Architecture & Engineering

How Vitals monitors your Mac without slowing it down.

Most monitoring utilities are bulky Electron wrappers or background Python daemons that consume hundreds of megabytes of RAM and spike your CPU just to report CPU usage. Vitals was built differently: 100% native Swift, Mach subroutines, and zero cloud telemetry.

⚡ Direct Mach Kernel Calls< 0.1% CPU

Instead of spawning shell commands like top or vm_stat, Vitals taps directly into Mach kernel APIs: host_statistics64, processor_info, and proc_pidinfo. This allows ultra-fast sub-millisecond polling with negligible CPU overhead and minimal battery drain.

🧠 Local LLM & VRAM ProfilingApple Silicon

Running local AI models with Ollama, LM Studio, or llama.cpp? Vitals continuously tracks unified memory VRAM headroom, inference tokens/sec, and active model footprints so you know exactly when a model will cause memory swapping.

🔥 Per-Core P/E Cluster TelemetryHardware

Inspect how macOS distributes threads between Performance (P) cores and Efficiency (E) cores in real time. Detect thermal throttling instantly before your compile jobs or video renders slow down.

🔋 Battery Vampire DetectionSmart Alerts

Identifies runaway background processes and apps preventing sleep. Vitals tracks system power draw in live watts and flags excessive drain when running on battery before you leave your desk.

Under-the-Hood Technical Specifications
Programming Language
100% Native Swift & SwiftUI. Zero webview wrappers, zero Python or Node dependencies.
Kernel Subroutines
Mach kernel calls: host_processor_info() for per-core loads, vm_statistics64() for memory pressure, and IOReport for Apple Silicon energy telemetry.
Historical Storage
Local encrypted SQLite database stored at ~/Library/Application Support/Vitals. Up to 30 days of metrics charted locally with zero cloud synchronization.
RAM Footprint
Typically 18 MB to 28 MB in regular operation — less than one browser tab.
Zero Data Collection Guarantee: Vitals collects zero analytics, contains no third-party tracking SDKs, and communicates with no remote telemetry servers. All sensor readings and history charts remain strictly on your Mac.
