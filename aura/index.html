Four engines, picked automatically

Runs on your Mac, not someone's server.

Aura chooses the best engine that's actually available — best result for the least cost to you — and you can pin a specific one in Settings. Whichever it uses, the text never leaves your Mac.

  • ✓Apple Intelligence — the on-device model built into macOS 26+. No download, nothing to set up.
  • ✓Aura's own model — one click downloads a quantized Llama that runs in-process on the GPU via MLX. Offline forever after.
  • ✓Local server — point Aura at LM Studio or Ollama on localhost. Loopback only, so it stays offline.
  • ✓Built-in cleanup — a no-AI grammar/mechanics pass that always works, even before you download a thing.
